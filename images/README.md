# Фотографии сайта АРМАДА

Фотографии для сайта хранятся в этом репозитории, а не в Supabase Storage.

## Как добавить фотографию

1. Открой репозиторий: https://github.com/valbr-dev/visisite
2. Перейди в папку `images` (для проектов можно создать подпапку `projects`, для других фото — `gallery`, `about` и т. п.).
3. Нажми **Add file → Upload files**, перетащи фотографию и создай commit.
4. После публикации GitHub Pages используй адрес вида:

   `https://valbr-dev.github.io/visisite/images/projects/имя-файла.webp`

5. В админке открой нужный раздел и вставь ссылку в поле фотографии. Можно вставить и относительный путь, например `images/projects/house-1.webp`.
6. Нажми «Сохранить изменения».

## Рекомендации

- Предпочтительный формат — WebP или AVIF; также поддерживаются JPG и PNG.
- Для фотографий сайта желательно заранее уменьшать разрешение и сжимать файлы.
- Давай файлам латинские имена без пробелов, например `modern-house-01.webp`.
- Не загружай в репозиторий оригиналы по десятки мегабайт: GitHub ограничивает размер отдельных файлов, а большие изображения замедляют сайт.
- Файлы в публичном репозитории доступны всем посетителям сайта.

Supabase по-прежнему используется для хранения текстового контента и авторизации администратора. Для фотографий Supabase Storage больше не используется.
