# Подключение админ-панели АРМАДА

Адрес редактора после публикации: https://valbr-dev.github.io/visisite/admin/

## 1. Создай проект Supabase
1. Открой https://supabase.com/ и зарегистрируйся.
2. Создай новый проект (регион можно выбрать ближайший к основной аудитории сайта).
3. Дождись завершения создания проекта.
4. В Project Settings -> API скопируй Project URL и anon / publishable key. Не копируй service_role key.

## 2. Создай таблицу и хранилище
1. В Supabase открой SQL Editor -> New query.
2. Открой файл supabase-setup.sql в этом репозитории, скопируй весь SQL и выполни его кнопкой Run.
3. В Authentication -> Sign In / Providers отключи публичную регистрацию (Allow new users to sign up).

## 3. Создай свой аккаунт администратора
1. Открой Authentication -> Users -> Add user.
2. Создай пользователя со своим email и надёжным паролем.
3. Если доступна настройка подтверждения email, подтверди созданного пользователя.
4. Не создавай других пользователей и не включай публичную регистрацию.

## 4. Подключи проект к сайту
1. Открой файл supabase-config.js в GitHub.
2. Вставь Project URL и anon / publishable key в соответствующие кавычки:
   - ARMADA_SUPABASE_URL
   - ARMADA_SUPABASE_ANON_KEY
3. Сохрани изменения (Commit changes).

Anon/publishable key предназначен для использования на клиенте. Безопасность обеспечивают RLS-политики из SQL-файла. Никогда не вставляй в этот файл service_role key или пароль.

## 5. Используй редактор
Открой https://valbr-dev.github.io/visisite/admin/, войди по созданному email и паролю. Выбирай раздел слева, редактируй поля, загружай изображения (до 10 МБ, JPG/PNG/WebP/AVIF) и нажимай «Сохранить изменения».
